Money Reels
===========

The Money Reels app and its data, in one repo.

- `index.html`: the app (Instagram-Reels-style news feed). It loads `posts.json` from this repo.
- `posts.json`: the feed. A scheduled Claude task adds new posts here every hour.

Live app (GitHub Pages): https://shadowprivacyscam-ship-it.github.io/money-reels-hourly-posts/
